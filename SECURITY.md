# Security policy

ShotDesk is a local-first desktop application. Please do not report suspected vulnerabilities in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/numera11y/shotdesk/security/advisories/new) to share a report. Include the affected version, operating system, reproduction steps, and impact. Do not attach private screenshots, image libraries, or database files unless they have been sanitized.

There are no published releases yet. Security fixes will be documented in the changelog and release notes when a public release channel is available.
